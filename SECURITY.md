# Security policy

## Reporting a vulnerability

Report it privately through GitHub's private vulnerability reporting: [open a report](https://github.com/yurtbayemre/sinnlos/security/advisories/new). Do not open a public issue or pull request for it.

We acknowledge a report within 7 days, keep you informed while we work on it, and publish a GitHub security advisory with the fixed release. Please give us reasonable time to ship the fix before you disclose it.

## Supported versions

Until v1.0.0, only the latest **stable** release gets security fixes (release candidates and older releases do not). Each release's notes on GitHub carry "Upgrade notes" and "Breaking changes"; read them before upgrading.

## Security model

How sinnlos protects its data (roles, the permission matrix, route policies, uploads, sign-in) is described in [docs/security.md](./docs/security.md).
